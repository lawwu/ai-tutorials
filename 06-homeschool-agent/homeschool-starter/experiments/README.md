# experiments/ — things you're trying

One file per experiment, with dated observations appended over time. Delete
this folder if you're not using it — it earns its place around month three,
not on day one.

## Why bother

Homeschooling is full of changes you make and then never evaluate. Did
moving math to the afternoon help? Did the reward chart do anything? Six
weeks later nobody remembers what it was like before. A file with dated
observations answers the question honestly.

## Format

```markdown
# Self-scheduling — CHILD_ONE

**Started** 2026-08-13
**Question** Can she plan her own school day from a task list?
**How we'll know** Does the work get done without prompting? Is the
morning calmer or worse?

## Observations

- 2026-08-13 — First day. Ordered her list sensibly, put math last,
  ran out of steam before it. Didn't complain about the system.
- 2026-08-20 — Week two. Moved math earlier on her own after the first
  day's lesson. Asked for a timer.
```

## Reviewing one

```
how is the self-scheduling experiment going?
```

The assistant should read the dated observations, synthesize a trend, and
answer honestly — what's working, what isn't, what to try next. That last
part is the whole reason to keep the file.
